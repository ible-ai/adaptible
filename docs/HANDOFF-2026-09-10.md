## Gotchas that cost hours

- **16 GB machine, one model process at a time.** Two resident 1.5B models
  → OOM killed background tasks. Always `pgrep -f adaptible` before launching.
- **`run_screen.sh` / `run_fixed.sh` write START/END markers to
  `outputs/runs/status.txt`.** Queued scripts wait on the END marker. Killing
  a parent shell loses its END marker → downstream queue hangs; write it by
  hand (`echo "[...] END <name> rc=..." >> outputs/runs/status.txt`).
- **Model-free tests only in CI.** Anything touching training must be
  smoke-tested on the real model (`--subset 4`, ~3 min) — three of today's
  crashes were shape/memory bugs no fake could catch.
- **Rationale generation can loop** (geo_003 reasons about Brazil for 800
  tokens): now used whole, truncated at 512 tokens; empty → item skipped.
- **`AGENTS.md`** is regenerated nightly by something on the user's machine
  (Codex sync, ~00:03). User said delete it. Consider `.gitignore`.
- Probe scripts live in `outputs/runs/probe_*.py`; run with `PYTHONPATH=.`
  and `LORA_RANK/LORA_LAYERS/LR/WRONG/PROBE` env vars.
